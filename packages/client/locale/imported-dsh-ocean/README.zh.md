# DSH Ocean 翻译导入

[English](README.md) | 中文

来源：已安装的 `@dsh-ocean/builtin-locales` **0.4.0** 版本，其中包含用户的俄语、西班牙语、巴西葡萄牙语、德语、法语、日语和韩语字典。原始源码仓库未作修改。

`catalogs.json` 原样保留原始数据（仅 JSON 格式有所调整）；`LICENSE` 保留 DSH Ocean 和 DeepSeek 的署名。`migration-report.json` 记录源客户端的 SHA-256、计数，以及因占位符、命令或 API 标记不匹配而拒绝的条目。

## 兼容性策略

- 按当前命名空间和键匹配，绝不根据其他命名空间中相似的标签匹配。
- 保留当前英文中的占位符、斜杠命令和 API 字段标记。不导入无法匹配或已废弃的键，也不导入不可见 Unicode 标记。
- 新增键保留当前翻译。将旧 `pt-BR` 字典映射到现有的 `pt` 语言（应用已能解析巴西葡萄牙语浏览器标签）。
- 将产品标记 `DSH` 替换为 `Ocean-Chat`，但保留 DeepSeek 提供方／模型名称及法律署名。
- 韩语通过现有 locale 服务仅注册匹配的键，以英文作为回退。上游一致性检查有意不将其列为完整语言。
- 完整上游界面的规模大于旧语言包。某种语言出现在设置中，并不能证明此次导入已翻译所有当前界面。

前端继续维护当前字典归属及 HMR（热模块替换）资源释放。导入的字符串整合到各自所属的命名空间；韩语注册由 locale 插件拥有，并随插件卸载而释放。
