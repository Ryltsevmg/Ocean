# Ocean Linux Computer Use（实验性）

[English](README.md) | 中文

## 概述

此可选提供方使用已有 Ocean CUA 应用授权及执行日志流程。它读取 AT-SPI 无障碍树，执行所选应用声明的语义操作。它不是整个桌面的远程控制。

<a id="requirements-and-activation"></a>
## 要求与激活

需要 Linux、可用的用户无障碍总线，以及带 PyGObject 和 Atspi 2.0 typelib 的系统 Python 3。默认解释器为 `/usr/bin/python3`，不是 Ocean 自带的 Python。本插件不安装软件包、不更改无障碍设置，也不启动守护进程。缺少依赖时明确报告不支持。部分应用需要用户先启用应用自身的无障碍支持，才会提供 AT-SPI。

可选 Computer Use 包在 Linux 上选择此提供方。分发此包并不启用组合包或授予应用访问权。读取应用内容或执行操作前，必须在 Ocean 中逐一选择并批准应用。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `pythonPath` | `/usr/bin/python3` | 具备 AT-SPI 绑定的系统 Python 绝对路径 |
| `sessionId` | 未设置 | 无法通过进程发现时显式指定 logind 图形会话 ID |
| `maxElements`, `maxDepth` | `500`, `20` | 无障碍快照限制 |
| `maxRequestBytes`, `maxResponseBytes` | `65536`, `1048576` | 辅助进程通信限制 |

### 显式绑定图形会话

默认情况下，辅助进程向 logind 查询自身进程的会话。由用户服务管理器启动的桌面程序可能没有此类会话。管理员确认用户预期的图形会话后，可在提供方配置中显式设置 `sessionId`。插件不读取环境变量，也不会静默选择其他会话。

显式绑定要求当前 UID 恰好拥有一个图形会话，且必须匹配配置 ID、位于本地、处于活动状态、附属于 seat，并报告 `LockedHint=false`。辅助进程固定会话身份，每次受保护操作都检查它。绑定后会话被替换或无法验证会话信息时，该辅助进程在剩余生命周期内失效；应重新连接并授权，不要重试过期句柄。logind 数据缺失或不可读，或者存在多个图形会话时，均拒绝访问。这不会更改系统无障碍权限或锁屏策略。

无障碍总线仍覆盖整个用户。会话绑定是保守的资格检查，不是内核强制的隔离边界；logind 锁定提示与操作也不是原子的。仍需真实环境试用验证和共享的逐应用授权。

<a id="model-experience"></a>
## 模型体验

### 无障碍操作

#### 模型看到什么

已有 `cua`/`cua_run_code` API 仅支持发现、所选应用或窗口的无障碍快照、操作列表与语义操作调用。快照有大小限制，并替换先前引用集合。密码及受保护控件被排除。更大的树消耗更多 token；重复读取不复用过期元素引用。

#### Token 影响

有大小限制的无障碍快照和操作列表占用模型上下文；更大的树消耗更多 token。

#### KV Cache 影响

提供方激活通过共享 CUA 流程添加 Linux 无障碍能力及指导。新观测替换先前元素引用，而不恢复过期句柄。

## 已知限制与待办工作
<a id="known-limitations-and-deferred-work"></a>

每个 Agent 拥有独立辅助进程和不透明句柄。操作检查所选进程身份及当前元素所有权；过期、失效或其他所有者的句柄被拒绝。取消会终止辅助进程并使其句柄失效。已交付应用的操作无法撤销，也不会自动重试。

- 观测和操作要求 logind 验证本地活动图形会话，且 `LockedHint=false`。未知或锁定会话均被拒绝。这是报告状态检查，不是操作系统强制的逐应用沙箱。
- 不支持截图、全屏观测、剪贴板、原始键盘或指针注入、焦点更改及应用启动。
- 不支持未提供 AT-SPI 的应用；这不是通用 Hyprland 适配器。
- 无障碍语义由应用提供。获准应用的内容仍不可信，可能包含指令；应用声明的操作可能产生真实后果，仍须遵循 Agent 的普通审批策略。
- 不声称具备操作系统强制的逐应用隔离：用户会话无障碍总线自身具备更广权限。提供方与共享 Ocean 授权层限制被接纳的调用，而不限制以该用户身份运行的第三方代码。
- 为用户安装或启用前必须通过真实图形会话验证。模拟测试不能确认每个应用的 AT-SPI 行为。
