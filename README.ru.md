Ocean — настольное рабочее пространство для ИИ-агентов, диалогов и инструментов. Плагины подключают провайдеров моделей, инструменты разработки, а при необходимости — управление браузером и компьютером.

<a id="developer-preview"></a>

## Предварительная версия для разработчиков

Ocean активно развивается. API и функции могут меняться. Перед запуском прочитайте [рекомендации по безопасности](SAFETY.md). Успешная локальная сборка не заменяет аудит безопасности или выпуск подписанной публичной версии.

<a id="get-started"></a>

## Начало работы

Используйте репозиторий [Ryltsevmg/Ocean](https://github.com/Ryltsevmg/Ocean). Пока готовится публичный выпуск, доступ может быть ограничен. Не устанавливайте Ocean через установщик исходного проекта или непроверенный пакет npm.

Порядок сборки из исходников и команды запуска веб-клиента и настольного приложения описаны в [руководстве по разработке](docs/development.md). Требования и команды определены в [package.json](package.json). Сохраните резервную копию профилей перед проверкой новой сборки.
