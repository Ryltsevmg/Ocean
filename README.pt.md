Ocean é um espaço de trabalho de desktop para agentes de IA, conversas e ferramentas. Seu ambiente de execução baseado em plugins conecta provedores de modelos, ferramentas de desenvolvimento e controles opcionais do navegador ou do computador.

<a id="developer-preview"></a>

## Prévia para desenvolvedores

O Ocean está em desenvolvimento ativo. As APIs e os recursos podem mudar. Leia o [aviso de segurança](SAFETY.md) antes de executá-lo; uma compilação local bem-sucedida não equivale a uma auditoria de segurança ou a uma versão pública assinada.

<a id="get-started"></a>

## Primeiros passos

Use este repositório: [Ryltsevmg/Ocean](https://github.com/Ryltsevmg/Ocean). O acesso pode estar restrito enquanto a versão pública é preparada. Não use um instalador do projeto original nem um pacote npm não verificado como método de instalação do Ocean.

Para preparar o repositório e consultar os comandos para executar Web e Desktop localmente, siga o [guia de desenvolvimento](docs/development.md). Os requisitos e as definições dos comandos são mantidos em [package.json](package.json). Guarde um backup dos perfis existentes antes de testar uma nova compilação.
