Ocean은 AI 에이전트, 대화, 도구를 위한 데스크톱 작업 공간입니다. 플러그인 기반 런타임이 모델 제공업체, 개발 도구, 선택적인 브라우저 및 컴퓨터 제어 기능을 연결합니다.

<a id="developer-preview"></a>

## 개발자 프리뷰

Ocean은 활발히 개발 중입니다. API와 기능은 변경될 수 있습니다. 실행하기 전에 [안전 안내](SAFETY.md)를 읽으세요. 로컬 빌드가 성공했다고 해서 보안 감사를 거쳤거나 서명된 공개 릴리스라는 뜻은 아닙니다.

<a id="get-started"></a>

## 시작하기

이 저장소를 사용하세요: [Ryltsevmg/Ocean](https://github.com/Ryltsevmg/Ocean). 공개 릴리스를 준비하는 동안 접근이 제한될 수 있습니다. Ocean 설치에 업스트림 설치 프로그램이나 검증되지 않은 npm 패키지를 사용하지 마세요.

소스 설정과 로컬 Web/Desktop 명령은 [개발 가이드](docs/development.md)를 따르세요. 요구 사항과 명령 정의는 [package.json](package.json)에서 관리합니다. 새 빌드를 테스트하기 전에 기존 프로필을 백업하세요.
