# 读取版本 2 的插件目录索引

[English](guide.md) | 中文

## 变更

`plugin-catalog` 分支中的公开插件索引 `v1/current.json` 现在携带 `schemaVersion: 2`。每个条目可以增加内联 `icon` data URL 和本地化的 `detail` Markdown 说明，「目录」标签页将其显示为卡片图标，并在**详情**中显示长说明。

Ocean 1.0.0 只接受 `schemaVersion: 1`，其他版本会让整个索引被拒绝，因此在版本 2 索引下，1.0.0 客户端会显示**已发布的插件目录不可用**。升级到下一个发布版本后目录恢复。保持版本 1 的索引在两个版本中都可用，只是不显示图标和长说明。自定义 `publishedCatalogUrl` 渠道遵循同一规则。

## 迁移

1. 在向用户读取的渠道发布版本 2 索引之前，先把 Ocean 升级到 1.0.0 之后的发布版本。
2. 如果自行运营渠道，请在每个读取端升级前保持 `schemaVersion: 1`，或同时提供两份：路径不受限制，例如用 `v1/current-v1.json` 存放供旧读取端使用的纯元数据索引。
3. 打开**插件 → 目录**确认迁移：卡片显示图标，**详情**显示长说明，且没有读取端报告目录不可用。
