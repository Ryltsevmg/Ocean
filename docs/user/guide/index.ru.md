# Работа в веб-интерфейсе

Запустите веб-интерфейс по [руководству по разработке](../../development.md). Команда выведет его URL. Дальнейшие шаги рассчитаны на уже запущенный сервер. Процесс `ocean` по умолчанию работает с каталогом, из которого его запустили. В новом веб-интерфейсе рабочее пространство нужно добавить и выбрать.

<a id="configure-a-model"></a>

## Настройте модель

Откройте **Настройки → Модели** и выберите провайдера. Поддерживаемые провайдеры и пользовательские точки подключения, совместимые с OpenAI, описаны в [руководстве по настройке моделей](./providers.ru.md). Для подключения DeepSeek введите свой [ключ API DeepSeek](https://platform.deepseek.com/) и сохраните настройки. Модель можно использовать сразу, без перезапуска сервера.

<a id="choose-a-workspace"></a>

## Выберите рабочее пространство

Нажмите **Выбрать рабочее пространство**, добавьте каталог проекта, из которого запустили `ocean`, и выберите его. Поле ввода в чате станет доступно после выбора рабочего пространства.

<a id="run-a-task"></a>

## Запустите задачу

Начните сессию и отправьте сообщение:

> Кратко опиши этот репозиторий и назови его основные пакеты.

Агент может читать и редактировать файлы рабочего пространства, выполнять команды, делегировать работу и вести план. Веб-интерфейс запрашивает подтверждение для операций, которым оно требуется по действующим настройкам разрешений.
