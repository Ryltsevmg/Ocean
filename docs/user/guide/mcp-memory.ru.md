Эти три базовые конфигурации **по умолчанию** соединяют одну систему памяти с DSH через [`@ocean/ocean-mcp-client`](../../../packages/mcp/mcp-client/README.md). Выберите одну из них или скопируйте одну и ту же общую строку MCP для другого сервера.

Эти конфигурации третьих сторон приводятся только в качестве примеров совместимости. Их включение не подразумевает одобрения, рекомендации, партнерства или постоянной поддержки со стороны проекта Ocean.

<a id="what-dsh-does"></a>

## Что делает DSH

DSH анализирует выбранное наложение Cordis, запускает настроенную команду stdio или подключается к настроенному потоковому URL HTTP, обнаруживает инструменты MCP и выдает их как `mcp__<serverName>__<tool>`. DSH делает **, а не** , загружает сервер, инициализирует свою базу данных, выбирает модель или поставщика встраивания, создает облачную учетную запись, перемещает данные поставщика или контролирует отдельную службу HTTP. Для stdio общий клиент запускает и останавливает ребенка с помощью жизненного цикла плагина DSH; для HTTP служба восходящего потока уже должна работать.

Стио-мост намеренно удаляет переменные окружающей среды, имена которых обычно идентифицируют учетные данные и все переменные `DSH_*` перед запуском ребенка; другие переменные окружающей среды остаются наследственными. Каждый пример добавляет только базовую отметку, которая ему нужна. Если опциональная функция upstream нуждается в другом секрете, добавьте эту переменную в строку `config.env` вместо того, чтобы помещать секрет непосредственно в YAML.

## Выберите один

| Система | Тестируемый штырь | Транспорт | Предварительное условие Upstream |
|---|---:|---|---|
| [Memorix](https://github.com/AVIDS2/memorix) | `memorix@1.3.0` (`500792cad3144142293bfbb20acb4841c9f7fcfa`) | stdio | Node 22.18+ `npm install --global memorix@1.3.0` |
| [Справочная память MCP](https://github.com/modelcontextprotocol/servers/tree/main/src/memory) | `@modelcontextprotocol/server-memory@2026.7.4` (`6dd0a683e198783e30feabf7abaf42f925bd18b1`) | stdio | `npm install --global @modelcontextprotocol/server-memory@2026.7.4` |
| [Engram](https://github.com/Gentleman-Programming/engram) | `v1.20.0` (`ba9e46ced152c37a7cb9e576153c41995873e2fc`) | stdio | Go 1.25.10+ и `go install github.com/Gentleman-Programming/engram/cmd/engram@v1.20.0`, или бинарный релиз |

<a id="enable-one"></a>

## Позволить одному

Передайте одну накладку DSH:

```sh
dsh web --patch "$PWD/apps/cli/config/examples/mcp-memory/memorix.cordis.yml"
```

Замените имя файла на `mcp-reference-memory.cordis.yml` или `engram.cordis.yml`. Путь может указывать на скопированный файл в любом месте на диске. Сервер памяти не присутствует в отправленной композиции, поэтому опускание `--patch` сохраняет все три отключенными.

Чтобы сохранить выбор между загрузками, объедините один патч `insert` выбранного файла в слой пользовательских патчей — `$DSH_HOME/profiles/<name>/cordis.patch.yml` для одного профиля или `$DSH_HOME/cordis.patch.yml` для каждого профиля на машине. Не копируйте существующий файл: он может уже содержать несвязанные патчи пользователя.

<a id="provider-setup"></a>

## Настройка провайдера

<a id="memorix"></a>

### Меморикс

```sh
npm install --global memorix@1.3.0
dsh web --patch "$PWD/apps/cli/config/examples/mcp-memory/memorix.cordis.yml"
```

Memorix работает в местном эвристическом режиме без LLM или службы встраивания. Настройка дополнительных провайдеров в собственном `~/.memorix/config.toml` компании Memorix или в проекте `memorix.toml`. Пример сохраняет идентичность Git-проекта Memorix из рабочего каталога DSH и использует собственный `~/.memorix/data` по умолчанию. Установите `MEMORIX_DATA_DIR` перед началом DSH, чтобы переопределить его.

<a id="mcp-reference-memory"></a>

### MCP эталонная память

```sh
npm install --global @modelcontextprotocol/server-memory@2026.7.4
dsh web --patch "$PWD/apps/cli/config/examples/mcp-memory/mcp-reference-memory.cordis.yml"
```

Этот справочный сервер хранит локальный граф знаний и раскрывает сущность, отношение, наблюдение, чтение, поиск и открытые инструменты. Он не нуждается в модели или встраиваемом сервисе. Пример хранит JSONL в `$HOME/.dsh-mcp-reference-memory.jsonl` вместо установленного каталога пакетов npm. Установите `MEMORY_FILE_PATH` перед началом DSH, чтобы переопределить его.

Поиск — это подстроки, не зависящие от случая, совпадающие по именам, типам и наблюдениям объектов, а не семантический поиск. Сервер не добавляет вставки, автоматическое суммирование, разрешение конфликтов или политику забывания.

<a id="engram"></a>

### Энграмма

```sh
go install github.com/Gentleman-Programming/engram/cmd/engram@v1.20.0
dsh web --patch "$PWD/apps/cli/config/examples/mcp-memory/engram.cordis.yml"
```

Engram владеет хранилищем и выбором проекта: он по умолчанию использует `~/.engram` , обнаруживает проект Git из рабочего каталога DSH и принимает `ENGRAM_DATA_DIR` или `ENGRAM_PROJECT` в качестве переопределяемых параметров окружающей среды.

<a id="optional-shared-model-instruction"></a>

## Необязательное совместное обучение модели

Добавьте эту короткую, нейтральную для поставщика инструкцию к существующим инструкциям модели, если описания инструментов сервера не запускают надежное использование памяти:

> Когда пользователь просит вас что-то запомнить, позвоните в инструмент записи памяти. Когда историческая информация может быть актуальной, выполните поиск памяти и используйте соответствующие результаты.

Это только аддитивное руководство. Примеры не заменяют системную персону DSH.

<a id="verify-write-fresh-session-recall-and-use"></a>

## Проверяйте написание, свежий отзыв и использование

Используйте одно уникальное значение и сохраняйте объем хранилища поставщика неизменным на протяжении всего:

1. В сессии DSH A спросите: `Remember that my validation drink is lapsang-<unique suffix>.` Подтвердите модель, называемую инструментом записи провайдера, и инструмент вернулся к успеху.
2. Создайте DSH-сессию B в том же запущенном хосте. Не копируйте разговор сеанса А. Спросите: `What is my validation drink? Check memory.` Подтвердите модель, называемую инструментом поиска или отзыва провайдера, и верните значение.
3. Еще в сессии B спросите: `Use that preference to suggest one drink for the meeting.` Подтверждает, что ответ использует отозванное значение.

Требуется новый сеанс DSH; перезапуск хоста не требуется. Потерпевший крушение ребенок MCP запускает автоматическое переподключение с обратным выключением и повторной синхронизацией инструмента; инструменты остаются в списке и звонки выходят из строя только во время отключения, а после того, как бюджет переподключения исчерпан, инструменты не регистрируются, и повторное подключение прекращается до перезагрузки или перезагрузки. Первоначальное открытие является асинхронным, поэтому дождитесь инструментов `mcp__...` от поставщика, прежде чем отправлять первую подсказку для проверки.

<a id="bring-another-mcp-server"></a>

## Принесите еще один MCP-сервер

Копируйте одни и те же поля входа и используйте уникальный `id` . `serverName`:

```yaml
- insert:
    - id: memory-my-server
      name: '@ocean/ocean-mcp-client'
      config:
        serverName: my-memory
        transport: stdio
        command: my-memory-mcp
        args: []
        env: {}
        cwd: !!js process.cwd()
```

Для удаленного сервера используйте вместо этого `transport: streamable-http`, `url`и `headers` . Установка, идентификация, аутентификация, модели, встраивания, настойчивость и лицензирование остаются ответственностью провайдера.
