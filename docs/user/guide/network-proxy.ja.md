DSH はアウトバウンドリクエストをルーティングします。モデルコール、ウェブ検索、ページフェッチ、および MCP サーバーを HTTP 経由で行なうため、標準のプロキシ環境変数によって示されるプロキシを使用します。 起動時に読み込みます。もう何も設定する必要はありません。 設計またはランタイムの制限によって、以下に「何を直接滞在するか」に記載されているいくつかのパスは、直接滞在します。

<a id="export-the-variables"></a>

## 変数をエクスポートする

```sh
export HTTPS_PROXY=http://127.0.0.1:7890
export HTTP_PROXY=http://127.0.0.1:7890
```

シェルプロファイルの行を全て入れる `dsh` invocation は、それらを継承したり、 `$DSH_HOME/.env` (`~/.dsh/.env` デフォルトでは) API キーの横にある; エクスポートされた変数は、常にそのファイルの上に勝つ。 プロジェクト自身の `.env` 設定できません: 到着します `git clone`と DSH は、あなたのトラフィックがどこにあるかをリポジトリが決定するのではなく、起動を拒否します。

認証が必要なプロキシは、URL: `http://user:password@proxy.example:8080`でそれらを取ります。 DSHはURLをバックに印刷しません。 拒否された変数の診断名なので、ユーザー名もパスワードもどこに表示されません。

<a id="why-your-browser-is-proxied-but-your-terminal-is-not"></a>

## お使いのブラウザがプロキシされるのはなぜですか?端末は

これは最も一般的な驚きであり、それはDSHに特異的ではありません。 すべてのソフトウェアが従う単一の「システムプロキシ」はありません - 3つの関係のないメカニズムがあります。

| メカニズム | 誰がそれに従うか |
|---|---|
| オペレーティングシステムのプロキシ設定 | サファリ、ほとんどのネイティブ macOS アプリケーション、Chrome および Edge |
| ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ザ・ `HTTP_PROXY` / `HTTPS_PROXY` 環境変数 | `curl`, `git`, `npm`, `pip`, と DSH |
| TUNモード(仮想ネットワークインターフェース) | 全て、透明 |

Clash などのプロキシアプリケーションで「システムプロキシ」スイッチは、最初の1つだけを書き込みます。 ブラウザはそれを拾う; コマンドラインツールは決してそれを見ることができません。 そのため、変数をエクスポートするのは別のステップであり、 TUN モードをオンにすると、変数をまったく使わずに両方の作業が行われます。

DSH は、オペレーティングシステムのプロキシ設定を読み取りません。 変数をエクスポートするか、 TUN モードを使用します。

<a id="choose-what-stays-direct"></a>

## 直接滞在する場所を選ぶ

`NO_PROXY` 直接到達するホストのリスト:

```sh
export NO_PROXY=internal.example.com,.corp.example.com,registry.local
```

ホスト名を入力し、サブドメインごとにマッチします。 `NO_PROXY=example.com` 送信する `api.example.com` 直接。 一流の `.` または `*.` 受付けて、同じことを意味しています。エントリーは持ち運び可能です。 `:port`, , , `*` すべてを迂回します。

**CIDR の範囲は動作しません。** オペレーティング システム バイパス リストには、 `10.0.0.0/8` や `192.168.0.0/16`などのエントリが頻繁に含まれています。 `NO_PROXY` にコピーする効果はありません。 代わりにホスト名やドメイン サフィックスを使用してください。

リストする必要はありません `localhost` または `127.0.0.1`. DSHは、独自のWeb UIとローカルサーバーがプロキシとループを介してルーティングされるため、常にループバックを迂回します。

<a id="limits-worth-knowing"></a>

## 知っておく価値の限界

**靴下のプロキシはサポートされていません。** A `socks5://` 値は起動時に報告され、スキップされ、DSH は名前を付けたスキームを直接接続します。 `HTTPS_PROXY=socks5://…` を使用可能な `HTTP_PROXY` にすると、HTTP プロキシを借りるのではなく `https:` を直接残します。 プロキシアプリケーションの HTTP ポートの代わりに変数を指す — 両方を調べ、HTTP は通常、隣接するポート番号です。

**`ALL_PROXY` 単独で十分です。** DSH は、Node と curl が異なるにもかかわらず、両方のスキームのためにそれに戻ります。 `HTTPS_PROXY` を明示的に設定することはまだ明確です。

**TLS-インターセプト企業プロキシは、その証明書を必要とします。** プロキシが到達可能になったら、リクエストが証明書エラーで失敗した場合は、起動する前に、組織のCAバンドルでノードを指す:

```sh
export NODE_EXTRA_CA_CERTS=/path/to/corporate-ca.pem
```

Node はプロセス開始時にのみ変数を読み込むので、実行前にエクスポートします。 `dsh`.

**ツール DSH は、同じプロキシに従うために実行します。.** コマンドは、バッシュツール、 `git`, `gh`、および MCP サーバーで、これらすべての変数を継承する子プロセスとして開始しました。 子ノードプログラムは、独自のインストールされたランタイムを使用します: Node 22.21+ および Node 24+ は、これらの変数を表彰します。 古いランタイムは、直接接続します。 プロキシ変数の1つがDSHを拒否した値を保持している場合 — SOCKSURL, 言う — Nodeベースのツールは、起動に失敗するのではなく直接接続します, `curl` と `git` はまだその値を読みます.

**プロキシ URL のパスワードは、それらのツールにも達します。** `HTTPS_PROXY=http://alice:s3cret@proxy.example:8080` は通常の環境変数なので、モデルの書き込みを含むすべてのコマンド DSH が実行されます。読み込み、環境をプリントするコマンドは、保存されている出力にパスワードを入れます。 これは、変数がすでにシェルの他のすべてのものに対して振る舞う方法です。 その問題が発生した場合は、プロキシにクレデンシャルフリーのエントリポイントを与えたり、URLよりも他の方法を認証したりします。

<a id="what-stays-direct"></a>

## 直接滞在するもの

すべての DSH がプロキシを通過するわけではありません。

- **この機械のすべて。** ループバックは常に直接: `localhost`, 全体 `127.0.0.0/8` 範囲, `::1`, , , `0.0.0.0`. プロキシは、ローカルを聴くだけサービスに到達できません。
- **モデルの書き込みをコードします。** ワークフローワーカーと Node ptc-runtime プロセスがプロキシ設定を受けていないため、モデル権限のあるスクリプトはパスワードを扱うことができるプロキシ URL を読むことができません。 直接リクエストは、必要なプロキシ自身を構成し、実行サンドボックスの対象に残さなければなりません。
- **使用法 テレメトリー。** OTLP の輸出業者は、プロキシ構成の 1 つではなく、Node 独自の HTTP クライアントを使用しており、テレメトリーは直接接続し、直接エグレッシブがブロックされる場所を失敗するだけです。 DSHで行うことは、それに依存します。 `DSH_TELEMETRY_MODE=DISABLED` を設定して、完全にオフにします。
- **`web_fetch` 専用アドレスへ。** アドレスを命名するURL `http://10.0.0.5/` プロキシに渡すよりも、プロキシに渡されるのではなく、プロキシが構成されていない同じ拒否を拒否されます。

<a id="check-that-it-worked"></a>

## それが働いたことをチェックする

エージェントがページをフェッチし、プロキシアプリケーションの接続ログを監視するように依頼します。

```sh
dsh --profile headless "fetch https://example.com and tell me the page title"
```

リクエストが表示されない場合は、変数が DSH 自身の環境に存続することを確認します。

```sh
env | grep -i proxy
```
