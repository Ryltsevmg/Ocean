Usage: ocean [--profile] <name> [options] [app-args...]
       ocean plugin --profile <name> <pnpm-args...>

ocean: boot an Ocean profile — an ordered stack of plugin-bundle patch layers
under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 ocean --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $OCEAN_HOME/profiles to boot
  --from-default-profile <name>  replace a custom profile with a fresh copy of a
                                 shipped profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  ocean web                                   boot the web profile (same as: ocean --profile web)
  ocean rescue --from-default-profile web
                                            recreate rescue from the shipped web template, then boot it
  ocean headless "run the tests"              answer one task, print the result, and exit
  ocean tui --patch ./extra.yml               boot a custom profile with one extra overlay
  ocean tui --resume <session>                arguments after the launcher flags reach the app
  ocean web --help                            the web app's own flags and help
  ocean plugin --profile tui add <package>    install a plugin into the tui profile
